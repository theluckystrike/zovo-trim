This branch starts at upstream commit `16dd5604c989a3ee8eab86416cc5ad35ee4fd746`. It retains the upstream history, copyright notices, GPL license, segment/action data model, and the proven scheduling principles of rescheduling at play, seek, rate, and media lifecycle boundaries.

## Version 1.0.0

- Replaced community-backed YouTube behavior in the packaged build with a fully personal editor for HTML5 video on any ordinary web page.
- Added per-URL local rule sets in `chrome.storage.local`.
- Added active-video start/end capture and per-region skip or mute actions.
- Added replay automation with overlap-safe seeks and mute-state restoration.
- Added JSON backup and restore through Blob download and file input.
- Added an original `tfg-` interface, storage namespace, icon family, popup, library, and onboarding flow.
- Added a build-time-required public Supabase key and valid-response-only license activation. No response tier string grants access.
- Added a free saved-URL allowance and a paid unlimited-rule entitlement. As required by GPL, complete corresponding source is provided and may be rebuilt without that product policy.
- Removed shared-database reads, segment submissions, votes, and playback telemetry from the packaged build.
