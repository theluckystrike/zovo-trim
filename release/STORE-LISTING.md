# Chrome Web Store listing

## Title

Zovo Trim

## Summary

Mark personal skip or mute regions on HTML5 videos. Rules stay local and replay automatically.

## Detailed description

Build a private cut list for videos you watch on the web.

Open the toolbar popup on a page with an HTML5 video, set the start point, move the playhead, and save the end. Each personal region can jump playback forward or mute the sound while the picture continues. The next time you open that same URL, your choices run automatically.

What it does:

- Captures start and end points from the active HTML5 video
- Saves personal skip and mute regions per page URL
- Applies local rules automatically on replay
- Restores the viewer's prior mute state after a mute region ends
- Lets you edit or delete exact region times in the library
- Exports the complete region set as one readable JSON file
- Imports a JSON backup through a local file picker
- Works in embedded video frames as well as top-level players

Privacy is the point. Video URLs, titles, times, and actions stay in local extension storage. There is no shared segment database, segment submission, voting, or playback telemetry. Optional license activation sends only the entered license key and this product's identifier to the verifier.

Free use includes personal rules for 10 saved video URLs. A verified license removes that saved-URL limit. Core editing and JSON export remain available without activation.
