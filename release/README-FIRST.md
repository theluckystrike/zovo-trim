# Zovo Trim 1.0.0 — submit-ready handoff

This folder is a release draft. It has **not** been submitted to the Chrome Web Store because all four publisher accounts were reported at their item cap.

## Reviewer path

1. Load `unpacked-load-this/` with Chrome's **Load unpacked** control.
2. Open a page containing an HTML5 `<video>` element.
3. Use the toolbar popup to set a start, set an end, and save either a skip or mute region.
4. Replay the range and confirm the per-URL action runs automatically.
5. Open the library to edit regions or exercise JSON export/import.

## Submission files

- `Zovo-Trim-v1.0.0.zip` — Chrome Web Store upload archive; `manifest.json` is at the ZIP root.
- `Zovo-Trim-v1.0.0-source.zip` — complete corresponding GPL-3.0 source snapshot.
- `release/STORE-LISTING.md` — listing copy and public URLs.
- `release/PERMISSIONS.md` — permission and data-use answers.
- `store-assets/` — exact-size screenshots, promotional images, and opaque store icon.
- `qa/` — baseline, design-loop, runtime, and gate evidence.
- `EVIDENCE-MANIFEST.sha256` — SHA-256 inventory for this handoff.
